# Format contract of the generated-file marker (ADL 0180). Read by GeneratedFileMarkerExamplesTest,
# .claude/hooks/tests/test-pre-tool-use-guard-generated-files.sh and test_verify_markers.py of the spec generator.
#
# A case starts with a line `=== <case name>`, followed by `key: value` lines:
#   file:   the file name the head is written to
#   syntax: DoubleSlash, NumberSign, XmlComment, Annotation (`@file:Generated`) or None
#   by:     the generator the head names; <none> for a hand-written file
#   source: the source the head names; <none> where it names none
#   hint:   one line of the regenerate hint, repeated for each further line
# `--- content` starts the body the marker is placed into (comment syntaxes only), `--- file` the
# complete file. Each section runs to the next section line or case line; every line ends in a
# line break.
